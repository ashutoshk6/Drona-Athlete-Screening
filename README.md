# Drona – Athlete Screening Platform

Drona is an athlete screening platform designed to make basic sports assessment and talent identification more accessible. It uses AI-based analysis and performance-related parameters to help evaluate an individual's athletic abilities.

The project focuses on simplifying the screening process through a digital platform that can collect assessment data, analyse performance and present the results in an understandable format.

## Features

- **Athlete Assessment:** Evaluate athletes using different physical performance parameters.
- **AI-Based Analysis:** Use computer vision and machine learning techniques to analyse relevant assessment data.
- **Performance Insights:** Present assessment results in a structured and understandable way.
- **Digital Records:** Maintain athlete assessment information for future reference.
- **User-Friendly Interface:** Provide a simple interface for interacting with the platform.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Python 3.x
- Node.js and npm
- Git

### Backend Setup

Clone the repository:

```bash
git clone https://github.com/ashutoshk6/Drona-Athlete-Screening.git
cd Drona-Athlete-Screening
```

Install Python dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python run_demo.py
```

### Frontend Setup

Navigate to the frontend directory:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
